# Privacy

YYZ Dev OS is a Skills-only Codex plugin. It does not operate a server, request an API key, create an account, or independently collect, transmit, sell, or store user data.

When a user invokes the Skill, Codex may read or modify project files only under the permissions, tools, and account settings chosen by that user. Users remain responsible for their project content and for reviewing changes before sharing or releasing them.

This page describes the plugin's intended data boundary. It does not replace platform, local, or project-specific privacy obligations. Review it before relying on it for a particular project or jurisdiction.
