# YYZ Dev OS

YYZ Dev OS is a Skills-only Codex plugin for personal software development. It supports both new projects and existing codebases: routine small changes stay lightweight, while recovery, security-sensitive work, releases, and major changes load only the safeguards their risk requires.

The plugin contains no MCP server, hosted backend, API key configuration, or plugin-managed data storage. It reads and modifies project files only through the Codex task permissions and tools available to the user. Its logo and composer icon are packaged in the plugin.

Support is available through the [issue tracker](https://github.com/eqd456-hub/yyz-dev-os/issues). Publication in the Codex directory is prepared for Portal submission but has not been submitted or approved. The Portal preview must be checked before submission because the verified individual publisher identity may appear on public listing surfaces.
